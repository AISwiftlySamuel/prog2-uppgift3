# prog2-uppgift3

Lärarbedömd uppgift 3 - Programmering nivå 2 (Hermods Komvux)

## Uppgift

Alternativ 1: Bibliotekssystem, implementerat i Python med objektorienterad
programmering.

## Klasser

- `Book` - en bok med titel, författare och ISBN
- `Member` - basklass för en bibliotekmedlem, hanterar lån och återlämning
- `StudentMedlem` - ärver från `Member`, har högre lånegräns
- `Library` - håller reda på alla böcker och medlemmar

## Köra programmet

python3 lararbedomd-uppgift-3.py

## Filer

- `lararbedomd-uppgift-3.py` - programfil för inlämning
- `lararbedomd-uppgift-3-uml.drawio` - UML-klassdiagram (planering)
